# NewsBook Admin (Web)

This is a simple Vite + React app scaffold for the NewsBook admin interface.

Quick start:

```bash
cd frontend-admin
npm install
npm run dev
```

Move or reimplement the admin pages from the existing `frontend/app` into this app's `src/` folder. Useful entry points:

- `src/App.jsx` — main app shell
- `src/main.jsx` — app bootstrap
